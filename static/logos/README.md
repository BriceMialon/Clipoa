# Logos des services (Clipoa)

Dépose ici les logos OFFICIELS fournis par chaque service (kits de marque), au format SVG ou PNG carré :

| Fichier | Où le trouver |
|---|---|
| `youtube.svg` | YouTube Brand Resources (icône « YouTube ») |
| `instagram.svg` | Meta Brand Resources → Instagram (glyphe) |
| `facebook.svg` | Meta Brand Resources → Facebook (logo « f ») |
| `tiktok.svg` | TikTok Brand Guidelines (icône) |
| `claude.svg` | Anthropic (Press / Brand) |
| `antigravity.svg` | Google Antigravity (kit presse) |
| `elevenlabs.svg` | ElevenLabs Brand Kit |

Tant qu'un fichier manque, Clipoa affiche une pastille de couleur avec l'initiale. `.png` est aussi accepté (même nom).
