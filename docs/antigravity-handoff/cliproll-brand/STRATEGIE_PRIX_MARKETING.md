# ClipRoll — Stratégie Prix & Marketing (Version Verrouillée BYOK)

## 1. Modèle & Prix verrouillés (Stripe)
- **Modèle** : **BYOK (Bring Your Own Keys)** — chaque utilisateur branche ses clés **Claude** + **ElevenLabs** (et bientôt **Gemini TTS** en option économique). **0 € de coûts variables IA pour ClipRoll.**
- **Mensuel** : **19 €/mois**
- **Annuel *(présélectionné par défaut)*** : **149 €/an** (~12,42 €/mois, soit **-35 %**)
- **Offre Fondateur (lancement, 100 premiers)** : ex. **99 €/an la première année** (ou code promo `-33 %` sur l'annuel)
- **Portail Stripe + Anti-churn** : pause 1 mois ou `-30 %` pendant 2 mois avant annulation.
- **Pré-requis techniques avant lancement public** : notarisation macOS (Apple Developer ID) + signature Windows (SmartScreen) + rapport de plantage.

## 2. Positionnement Marketing (CRUCIAL à ce prix)
Avec 10–20 €/mois d'API en plus, le client paie **~30–40 €/mois au total** (niveau Crayo, et au-dessus de ShortCrew 79 € one-time après 4 mois).
**→ Ne JAMAIS vendre ClipRoll sur « le moins cher ».**

Vendre les **3 piliers Premium** qui écrasent les SaaS cloud et les outils one-time basiques :
1. **Qualité Studio (pas de « slop IA »)** : la qualité des scripts Claude + voix ElevenLabs + rythme/sous-titres doit se voir dès les 3 premières secondes de la démo vidéo sur `cliproll.app`.
2. **Vrai Illimité sans piège à crédits** : sur Crayo/StoryShort/InVideo, chaque régénération brûle tes crédits. Sur ClipRoll, **0 quota logiciel** : tu paies ton API à prix coûtant (zéro marge cachée sur les tokens) et tu produis en illimité — plus tu produis (ex. 2–5 Shorts/jour sur plusieurs chaînes), plus ClipRoll devient **beaucoup moins cher** que n'importe quel SaaS à crédits.
3. **100 % Local, Privé & Propriétaire** : tes projets, scripts, voix et vidéos restent sur ton Mac/PC, aucune dépendance à un cloud tiers, mises à jour continues (ce qui justifie l'abonnement face à un outil one-time vite abandonné comme ShortCrew).

## 3. Ce qui doit absolument compenser la friction d'installation (2 Go + clés API + ~20 min rendu)
- **Assistant de setup 3 étapes guidé dans l'app** (avec liens directs vers console.anthropic.com & elevenlabs.io + bouton « Tester mes clés » + barre de téléchargement claire pour les 2 Go).
- **Démo vidéo 30s irrésistible sur `cliproll.app`** montrant 3 vrais Shorts produits par ClipRoll (preuve de qualité avant de demander le téléchargement).
- **Option Gemini TTS** en voix alternative dans l'app → permet au client de diviser sa facture API vocale s'il le souhaite (argument marketing bonus très fort !).

## 4. Acquisition (Plan 90 jours adapté BYOK Premium)
1. **Dogfooding qualité** : 2 chaînes TikTok/Shorts/Reels alimentées par ClipRoll où la **qualité visuelle/narration** est clairement au-dessus du lot + série *Build in Public*.
2. **Affiliation créateurs (30 % récurrent)** : cibler les créateurs « YouTube Automation / Chaînes Faceless / Outils IA » qui produisent en volume (pour eux, l'illimité à prix coûtant API est un no-brainer à 149 €/an).
3. **Pages comparatives SEO (`cliproll.app`)** : *ClipRoll vs Crayo* (pas de crédits qui fondent), *ClipRoll vs ShortCrew* (mises à jour continues, macOS + Windows, qualité studio), *ClipRoll vs StoryShort*.
4. **Lancement Product Hunt + X + Reddit** (`r/YouTubeCreators`, `r/NewTubers`, `r/SideProject`) avec l'offre Fondateur limitée.
